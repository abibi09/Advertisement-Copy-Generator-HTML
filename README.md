# AdSpark — Advertisement Copy Generator

## About the Project
AdSpark is a web-based advertisement copy generator built using HTML, CSS, and JavaScript. It helps users create advertisement copy variations for different marketing platforms.

## Features
- Enter product or service details
- Select advertising platforms
- Choose a writing tone
- Specify the target audience and advertising goal
- Generate three advertisement copy variations
- Copy individual advertisements or all variations
- Clear results and generate new advertisements
- Responsive interface for desktop and mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter the product details and select your preferences.
4. Click **Generate Advertisement Copy**.

## Note
This project uses JavaScript-based templates to generate advertisement variations. It does not currently connect to an external AI model.
